# SaveYourRoof How It Works Explainer

- **Audience:** Homeowners evaluating a gentle roof-cleaning service.
- **Purpose:** Explain the four-step soft-wash process clearly and build confidence before the quote CTA.
- **Duration target:** Approximately 70.76 seconds, based on the approved generated narration.
- **Output:** 1920×1080 minimum, editable HTML composition using HyperFrames and a single paused GSAP timeline.
- **Narration:** Warm, confident female voice; neutral U.S. English; professional home-services tone.
- **Structure:** Intro, APPLY, BREAK DOWN, RINSE, RESTORE — THE ADD-ON, branded end frame.
- **Interactive behavior:** Website player starts at roughly 50% viewport visibility. A clear “Play with sound” control unlocks narration after the visitor’s first tap or click. Leaving the section resets playback. Re-entering from either direction restarts from the beginning.
- **Accessibility:** Captions are visible in the player, controls are keyboard accessible, and an HTML transcript/fallback repeats the complete four-step explanation.
- **End frame:** Exact branded line `Clean · Restore · Save $` followed by an HTML `Get Quote Now` button centered below the player.
- **Render gate:** Do not render the final MP4 until the user approves the interactive preview.
